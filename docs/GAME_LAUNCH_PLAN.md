# 游戏上架与完善计划

## 当前状态（2026-11-04）

- WITHERROOT 与 STELLAR FORGE 已完成玩法整理、英文版本、封面/美术、移动端修整和内部浏览器回归；两款游戏已加入中英文试玩目录。Vite 双语构建、项目类型检查和 Next.js 生产构建均通过。
- 本地生产构建中的中英文目录与游戏入口已核对。此工作区尚未部署到 Vercel：CLI 登录已失效，需重新完成 Vercel 设备授权后发布并检查线上流程。
- 当前验证来自内部自动化浏览器回归；没有进行外部首次玩家可用性测试，不把内部验证描述成外部试玩结果。

## 后续游戏的制作顺序

已公开目录原有三款游戏；本次为 WITHERROOT 与 STELLAR FORGE 完成双语试玩版本并加入目录。Office Cringe 的英文副本是私有测试草稿；它不替换现有页面，也不算作公开版本。

WITHERROOT 和 STELLAR FORGE 按以下顺序分别推进，任何一项未验收都不公开上架：

1. **玩法定稿：** 明确核心循环、胜负条件、关卡/波次节奏、教程、奖励和难度；先把玩法做完整并确认可通关。
2. **美术完成：** 再统一游戏内视觉、界面图标、封面和商店截图；美术需匹配已经定稿的玩法与英文标题。
3. **英文化：** 玩法和文案稳定后翻译游戏名称、教程、界面、剧情/关卡、奖励、错误提示及 itch.io 页面；逐屏检查无残留中文、截断或布局溢出。
4. **修 bug 与验收：** 对中英文版本做新存档完整流程、保存/刷新/重进、桌面与手机视口回归；修复阻断和严重问题后复测，并记录已知限制。
5. **上线：** 只有玩法、美术、英文版本和回归验收全部通过后，才加入公开游戏页并发布。

本次依次完善了 **WITHERROOT** 和 **STELLAR FORGE**。后续未完成游戏仍按“玩法 → 美术 → 英文化 → Bug 回归 → 上线”推进。

## WITHERROOT 完善计划

当前已完成五关渐进主线、关后遗物、刷新保留长期进度、英文副本、封面和内部五关通关回归；英文版在手机窄屏下已核对布局与操作。外部首次玩家测试仍未进行。

### 阶段 1：玩法定稿与平衡

- 明确五关各自的教学目标、胜利/失败条件、资源压力、霜冻节奏和遗物作用；调整目标与难度，使每关能教会一个新机制并有可复现的通关路线。
- 从新存档走完五关，覆盖胜利、失败、重试、领奖、下一关解锁、刷新和重进；确认进度、遗物只结算一次且不会丢失。
- 验收：一名未看说明的测试者可独立开始并完成至少前两关；五关均有可复现的通关路径；存档边界清楚。

### 阶段 2：美术与呈现

- 在玩法定稿后统一根系、灰烬、记忆节点、霜冻和遗物的视觉提示；完成对应图标、首页/关卡界面、封面与商店截图。
- 验收：关键机制可通过视觉区分；新美术不遮挡棋盘和操作，也不改变玩法信息含义。

### 阶段 3：英文化适配

- 英文化游戏标题、教程、关卡目标、动态提示、遗物名称/说明、设置、结算和商店页面；英文名称固定为 **WITHERROOT — Decay to Rebirth**。
- 验收：英文流程没有中文残留、文本截断或不自然的规则歧义；中英文切换和刷新后语言保存正常。

### 阶段 4：修 bug 与回归验收

- 邀请 5–8 名首次玩家，观察他们能否理解生长、灰烬、记忆节点、霜冻和遗物，不在过程中提示答案；记录并修复重复出现的理解障碍。
- 在窄屏竖屏、短屏横屏和桌面视口检查棋盘、奖励弹窗、语言切换、设置和触控；验证第三方 SDK 被拦截时游戏仍可开始和完成。
- 修复从新存档到五关结算流程中的阻断 bug；复测胜负、奖励防重复、进度保存、刷新重进与语言切换。
- 验收：没有阻断流程的问题；未通过的尺寸/浏览器有明确限制说明；完整回归结果有记录。

### 阶段 5：开放试玩与发布准备

- 更新作品集卡片、封面与英文/中文简介；从公开入口确认可直接进入，主线结束后可重玩或回菜单。
- 验收：已知问题和支持设备范围写清楚；完成共用上线门槛后再公开。

## STELLAR FORGE 完善计划

当前版本已改用 `HashRouter` 保留游戏入口；英文版为独立构建，首次进入会显示可完成的教程，不再预先标记教程或自动跳过剧情。已补上波次 20 首领胜利结局、移动端 HUD 和帮助页布局，并完成桌面/手机内部回归。外部首次玩家测试仍未进行。

### 阶段 1：玩法定稿

- 定稿元素切换、投放、自动攻击、融合、技能、五波敌人节奏与首领战的规则和胜负条件；每波的教学目标与战斗压力要对应实际机制。
- 将教程纳入正式玩法流程，删除“预先标记教程已完成”的写入和依赖按钮文案的自动跳过；首次访问必须能看到并完成教程。
- 验收：首次玩家能从教程理解基本操作，并能按规则完成一局；关闭提示、刷新或重新进入不会偷偷跳过教学。

### 阶段 2：美术与呈现

- 按玩法定稿统一元素、敌人、融合和首领的视觉反馈，完成图标、界面、封面与商店截图；不同元素及状态需清楚可辨。
- 验收：美术反馈能说明战斗状态与可执行操作，不遮挡主棋盘和控制区。

### 阶段 3：英文化适配

- 英文化游戏标题、教程、波次提示、元素/敌人/技能名称、战斗反馈、菜单设置和商店页面；英文名称固定为 **STELLAR FORGE**。
- 验收：英文运行流程无中文残留、文本截断或规则术语前后不一致；中英文布局均可读。

### 阶段 4：修 bug 与回归验收

- 修复 `history.replaceState(..., "/")` 导致的路径重写；以稳定子路径正确处理资源与地址，确保深链接、刷新、返回和分享链接都回到游戏。
- 从新存档完整试玩五波和首领战，覆盖元素切换、融合、技能、胜负结算、重开和存档恢复；检查每条提示是否与实际机制一致。
- 至少 5 名新玩家完成无提示试玩；根据误解点调整教程、敌人节奏和首领难度。测试手机触控、窄屏布局，以及 Google Fonts 不可用时的字体回退。
- 验收：新玩家能说明投放、自动攻击、融合和元素克制的基本关系；无卡死、失效按钮或刷新丢失；阻断级问题清零并留有完整回归记录。

### 阶段 5：开放试玩与发布准备

- 从作品集入口确认可直接进入游戏；写清已知问题和支持设备范围。
- 只有完成共用上线门槛后才加入公开游戏页。

## 共用上线门槛

- 每款游戏从作品集入口开始可玩，刷新、返回和直接访问深链接正常。
- 中文/英文页面文案、结局数、封面和实际玩法一致。
- 至少覆盖桌面和常见手机视口；没有遮挡主操作的弹窗或横向溢出。
- 上线前完成一次真实玩家试玩记录；试玩只用于发现明显阻碍，不把小样本结果表述为留存或转化结论。
- P0/P1 级问题清零；中英文版本均通过新玩家完整流程、刷新/存档恢复和响应式回归。
